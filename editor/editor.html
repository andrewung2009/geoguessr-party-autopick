Shorthand is the map's main code. Keywords are extra codes that also select it. Your friend can type any of them, then an optional mode: comp NM. The search field is what gets sent to GeoGuessr's map search, not what your friend types. Default mode is applied when the message has only the map; an explicit mode in the message overrides it.
